Tessel.js Fluent-inspired Web Components in plain JavaScript — the same design tokens, palette and control set as Tessel.NET, styled with Tailwind CSS and shipped as framework-free custom elements.
Import the entry module once, then use the tags directly in HTML: 
<script type="module" src="tessel/src/tessel.js"></script>

<tsl-button variant="accent">Save</tsl-button>
<tsl-date-picker header="Due date"></tsl-date-picker>
 Every component is a native custom element with its own shadow DOM. Tailwind is compiled ahead of time into one shared stylesheet that ships inside the package — consumers need no bundler, no framework and no CSS tooling.
